## 🚀 How to Run a Project

Since this is a collection of independent projects, you need to navigate into the specific project folder to run it.

1.  **Clone the repository:**

2.  **Navigate to the specific project folder:**

    ```bash
    cd Mobile-Development-Projects/GuessMyNumber
    # Replace "GuessMyNumber" with the project folder you want to run
    ```

3.  **Install dependencies:**

    ```bash
    npm install
    ```

4.  **Start the app:**
    ```bash
    npx expo start
    ```
